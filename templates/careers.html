채용

세상에서 가장 취약한 뱅킹 애플리케이션을 만들기 위해 지칠 줄 모르고 일하는 헌신적인 전문가 팀에 합류하세요.

왜 VulnBank에서 일해야 할까요?

저희는 매일같이 최첨단 보안 과제에 도전할 수 있는 특별한 기회를 제공합니다. 불안전함을 향한 저희의 헌신 덕분에 "시큐어 코딩"으로 지루한 하루를 보낼 일은 결코 없습니다. 저희는 단순히 무언가를 망가뜨리는 데 그치지 않고, 창의적인 방식으로 망가진 채 내버려 둡니다.

고용 안정성

요청 제한 없음, 입력 검증 없음, 의도적인 취약점까지 갖췄으니 고용 안정성은 보장됩니다. 저희만의 독특한 보안 태세를 "유지"할 개발자는 언제나 필요하니까요.

배움의 기회

모든 버그 리포트는 배움의 기회입니다! 사용자들이 저희도 몰랐던 취약점을 아낌없이 찾아 줍니다. 무료 모의 해킹 팀을 둔 것과 같죠.

워라밸

저희 장애는 영구적이라서 온콜 당번 같은 건 두지 않습니다. 한번 배포된 취약점은 계속 배포된 상태로 남습니다. 패치가 없으니 새벽 3시에 호출 알림이 올 일도 없습니다.

오픈 소스 문화

저희 소스 코드는 어차피 사실상 오픈 소스입니다. 디렉터리를 열거할 줄 아는 사람이라면 누구나 읽을 수 있죠. 저희는 과실을 통한 투명성을 지향합니다.

채용 중인 포지션

보안 엔지니어

엔지니어링

저희 보안 전략을 책임질 분을 찾습니다. 이상적인 지원자는 "관리자 패널이 왜 /sup3r_s3cr3t_admin에 있나요?"나 "비밀번호 해시 좀 하면 안 될까요?" 같은 질문을 하지 않습니다. 이 역할은 대부분 형식적입니다.

주요 업무:

  • "보안은 여정입니다"라는 내용의 블로그 글 작성
  • 코드 리뷰에서 누군가 데이터 암호화를 제안하면 사려 깊게 고개 끄덕이기
  • 홈페이지의 "마지막 침해 일시"를 가끔 업데이트하기
  • 사용자가 다른 사용자의 JWT 토큰을 훔칠 수 있는 XSS를 왜 못 고치는지 경영진에게 설명하기

자격 요건:

  • "은둔을 통한 보안"이 유효한 전략이라고 믿어야 함
  • "v2에서 고칠게요"를 정색하고 말할 수 있는 능력
  • 고객의 비밀번호가 왜 유출 데이터베이스에 있는지 태연하게 설명할 수 있는 분

백엔드 개발자

엔지니어링

취약한 뱅킹의 미래를 만들어 가는 성실한 개발자 팀에 합류하세요. 저희는 가장 진정한 의미의 "애자일" 개발을 실천합니다. 누군가 저희 인증 정보 테이블을 발견하면 재빨리 방향을 틉니다.

주요 업무:

  • 사용자 입력으로 SQL 쿼리를 바로 작성하기. 더 빠르고, 잘못될 게 뭐가 있겠어요?
  • 사용자가 대신 테스트해 줄 테니 테스트 없이 새 기능 구현하기
  • "의도적인 취약점"을 지적하는 보안 린터 사용 피하기
  • GitHub 이슈에 "제 컴퓨터에서는 잘 되는데요"라고 답변하기

자격 요건:

  • SQL 쿼리 문자열 이어 붙이기 경험
  • 시크릿을 환경 변수에 저장하는 일(그리고 그걸 커밋하는 일)에 익숙한 분
  • 관련 문서를 하나도 읽지 않고 인증을 구현할 수 있는 능력
  • JWT가 "Just Trust Us(그냥 믿어 주세요)"의 약자라고 생각해야 함

DevOps 엔지니어

인프라

저희 인프라는 애플리케이션만큼 안전합니다. 즉, 별로 안전하지 않습니다. "돌아가긴 한다"와 "처참하게 망가졌다" 사이의 아슬아슬한 균형을 유지해 줄 분을 찾습니다.

주요 업무:

  • 테스트 없이 코드를 프로덕션에 배포하기
  • 권한 없는 사용자를 포함한 모든 사람이 서버에 계속 접근할 수 있도록 보장하기
  • 어차피 무시할 모니터링 구축하기
  • 찾지 못한 무한 루프 때문에 메모리 사용량이 100%가 되면 가끔 서버 재시작하기

자격 요건:

  • 여러 번 해킹당한 서버를 다뤄 본 경험
  • "인증은 나중에 추가할게요"라는 말에 익숙한 분
  • 사용자가 한창 악용 중인 프로덕션 이슈를 태연하게 디버깅할 수 있는 분

고객 지원 전문가

고객 지원

고객이 잔액이 예기치 않게 바뀐 걸 알아챘을 때 최전선에서 대응하게 됩니다. 이 역할에는 인내심, 공감 능력, 그리고 "확인 중입니다"를 무기한 말할 수 있는 의지가 필요합니다.

주요 업무:

  • 누군가 비밀번호를 맞혀 버린 사용자의 계정 복구 돕기
  • 무단 거래가 "기능"이라고 설명하기
  • 저희 앱이 왜 해킹 포럼에 올라와 있는지 묻는 이메일에 답변하기
  • 취약점 제보를 /dev/null로 전달하기

자격 요건:

  • "고객님의 보안은 저희에게 중요합니다"를 웃지 않고 말할 수 있는 능력
  • 잘못을 인정하지 않는 이메일 작성 경험
  • "저희는 고객님의 개인정보를 소중히 여깁니다" 복붙 템플릿에 대한 지식
  • 보안 관련 경력이 없어야 함(괜히 답답하기만 할 테니까요)
